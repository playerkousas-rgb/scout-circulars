# Patch Notes v5.3 / v5.3.1

## 目標
唯一目標沒有變：

> 未來總會 / 地域 / 區會一有新更新，就可以穩定抓回來，並清楚顯示給成員看到。

---

## 已完成：資料入口層

### 1. 不再只抓 PDF
現在已改成抓 **downloadable assets**：

- pdf
- doc / docx
- xls / xlsx
- ppt / pptx
- zip / rar / 7z
- rtf / csv
- Google Drive 檔案型下載連結

### 2. 列表頁 + 內頁雙階段
流程：

1. 列表頁掃候選連結
2. 直接附件立即入庫
3. 文章頁再進內頁找附件
4. 新資產或原地覆蓋更新都刷新 `captured_date`

### 3. 來源隔離
唯一鍵已改成：

- `(source_site, pdf_url)`

避免不同區會引用同一條連結時互相污染。

### 4. cache.json 改為按來源分組
現在同時提供：

- `data[source]`：新前端分頁模式
- `notices[]`：舊工具兼容模式

## 已完成：逐站精修 sources.json

### 做法
不是單純全局 replace，而是分兩類：

#### A. 直接附件型來源
例如：

- 總會
- 港島地域
- 九龍地域
- 九龍塘區
- 荃灣區
- 新界地域
- 沙田東區
- 沙田北區

策略：

- `follow_detail_pages: false`
- `asset_link_selector` 聚焦直接下載資產

#### B. 新聞 / 文章型來源
例如：

- 灣仔區
- 柴灣區
- 筲箕灣區
- 紅磡區
- 油尖區
- 西貢區
- 慈雲山區
- 觀塘區
- 元朗西區
- 青衣區
- 雙魚區
- 沙田南區

策略：

- `follow_detail_pages: true`
- `detail_link_selector`
- `detail_max_pages`

讓 crawler 能先抓列表，再進內頁拿附件。

## 已完成：標題與亂碼清洗

### 1. 標題推斷加強
現在對直鏈附件，不再只信 anchor 本身文字。

會按順序嘗試：

1. anchor 文字
2. 同一列 / 同一容器的 `td / th / h2 / h3 / article` 內容
3. `title_selector` 鄰近元素
4. 容器全文
5. 最後才退回檔名

### 2. 已清掉的垃圾類型
會自動丟棄或修正：

- `下載`
- `download`
- `通告`
- `行政通告`
- `特別通告`
- 純日期
- 純代碼（如 `KLG/26-02/D` / `TPSDTVS202501`）
- 表頭字串
- 常見 mojibake / 亂碼碎片

### 3. 編碼修正
對錯設為 Big5 的來源，會按實際 `apparent_encoding` / UTF-8 回退。

已修好的典型來源：

- 新界地域（原本嚴重亂碼，現已正常中文）
